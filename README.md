# VK API Probe

Небольшая PWA для проверки доступности VK непосредственно с телефона или ноутбука через текущую сеть.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

## Что проверяется

- `vk.com`
- `m.vk.com`
- `api.vk.com`
- публичный вызов `users.get`
- `oauth.vk.com`
- статический ресурс VK

## Как проводить эксперимент

1. Запусти приложение через HTTPS-хостинг, доступный телефону.
2. Сделай замер через обычный Wi-Fi и экспортируй JSON.
3. Отключи Wi-Fi.
4. Во время ограничений мобильного интернета сделай второй замер.
5. Сравни результаты.

## Важное ограничение

Браузер — не полноценный сетевой диагностический инструмент. CORS, TLS, DNS и сетевые ограничения могут проявляться для `fetch()` похожим образом.

Тесты `no-cors` дают более полезный сигнал о достижимости хоста, но ответ является opaque: приложение не видит HTTP status и body.

Поэтому этот проект — первый диагностический этап, а не доказательство того, что конкретный VK API гарантированно работает через белый список.

## Следующий этап

- VK OAuth;
- авторизованные методы VK API;
